# Feature Catalog

All features are generated by `src/features/feature_store.py` from the registry in `src/features/registry.py`.
Snapshots are point-in-time: computed only from interactions at or before the snapshot `as_of` time.

| # | Feature | Entity | Type | Description | Logic | Source | Used by |
|---:|---|---|---|---|---|---|---|
| 1 | `user_rating_count` | user | int | Number of ratings given before the snapshot time | `count(ratings)` | interactions | hybrid, analysis |
| 2 | `user_avg_rating` | user | float | Mean rating given by the user (global mean for cold-start users) | `mean(rating)` | interactions | hybrid, item-kNN |
| 3 | `user_rating_std` | user | float | Standard deviation of the user's ratings | `std(rating)` | interactions | analysis |
| 4 | `user_positive_ratio` | user | float | Share of the user's ratings that are >= relevance threshold | `count(rating>=4)/count` | interactions | analysis |
| 5 | `user_active_days` | user | int | Distinct calendar days with at least one rating | `nunique(event_date)` | interactions | analysis |
| 6 | `user_tenure_days` | user | float | Days between first and last rating | `max(ts)-min(ts)` | interactions | analysis |
| 7 | `user_days_since_last_interaction` | user | float | Recency: days between the last rating and the snapshot time | `as_of - max(ts)` | interactions | analysis, monitoring |
| 8 | `user_preferred_genre` | user | category | Genre with the most positive ratings (min. support applies) | `argmax_g count(rating>=4 & genre=g)` | interactions + items | hybrid (explainability) |
| 9 | `user_genre_entropy` | user | float | Shannon entropy of the user's genre distribution (taste breadth) | `-sum p_g log2 p_g` | interactions + items | analysis |
| 10 | `user_mainstreamness` | user | float | Mean log-popularity of items the user rated | `mean(log1p(item_rating_count))` | interactions + item features | hybrid |
| 11 | `user_avg_release_year` | user | float | Mean release year of items the user rated | `mean(release_year)` | interactions + items | hybrid |
| 12 | `age` | user | int | User age (imputed by occupation median where missing/invalid) | `cleaned u.user.age` | users | cold-start |
| 13 | `age_bucket` | user | category | Age band <18, 18-24, 25-34, 35-44, 45-54, 55+ | `cut(age)` | users | cold-start segments |
| 14 | `gender` | user | category | M / F / U (unknown) | `cleaned u.user.gender` | users | cold-start segments |
| 15 | `occupation` | user | category | Lower-cased occupation | `cleaned u.user.occupation` | users | analysis |
| 16 | `is_cold_start` | user | bool | True if the user has no rating before the snapshot time | `user_rating_count == 0` | derived | routing (hybrid) |
| 17 | `item_rating_count` | item | int | Number of ratings received (popularity) | `count(ratings)` | interactions | popularity, hybrid |
| 18 | `item_avg_rating` | item | float | Raw mean rating (NaN if never rated) | `mean(rating)` | interactions | analysis |
| 19 | `item_bayesian_avg` | item | float | Bayesian-average rating shrunk toward the global mean (m = 20) | `(n*mean + m*mu)/(n+m)` | interactions | popularity, hybrid |
| 20 | `item_rating_std` | item | float | Standard deviation of the item's ratings (controversy) | `std(rating)` | interactions | analysis |
| 21 | `item_popularity_rank` | item | int | Rank by rating count (1 = most popular) | `rank(count, desc)` | interactions | popularity |
| 22 | `item_log_popularity` | item | float | log(1 + rating count) | `log1p(count)` | interactions | hybrid |
| 23 | `item_days_since_last_rating` | item | float | Days between the item's last rating and the snapshot time | `as_of - max(ts)` | interactions | analysis, monitoring |
| 24 | `item_release_year` | item | int | Release year (imputed from title when release date is missing) | `year(release_date)` | items | hybrid |
| 25 | `item_age_years` | item | float | Years between release date and snapshot time | `(as_of - release_date)/365.25` | items | analysis |
| 26 | `item_primary_genre` | item | category | First listed genre of the item | `first genre flag = 1` | items | diversity, analysis |
| 27 | `item_n_genres` | item | int | Number of genres the item belongs to | `sum(genre flags)` | items | analysis |
| 28 | `ui_genre_affinity` | user_item | float | Mean of the user's shrunk genre preference over the item's genres | `mean_{g in G(i)} sum(r-mu_u)/(n_ug+5)` | user genre profile + items | hybrid |
| 29 | `ui_popularity_gap` | user_item | float | Item log-popularity minus the user's mainstreamness | `item_log_popularity - user_mainstreamness` | user + item features | hybrid |
| 30 | `ui_release_year_gap` | user_item | float | Item release year minus user's average release year | `item_release_year - user_avg_release_year` | user + item features | analysis |
| 31 | `genre_<g>` x 19 | item | int | One-hot genre flags (unknown, Action, Adventure, Animation, Children, Comedy, Crime, Documentary, Drama, Fantasy, Film-Noir, Horror, Musical, Mystery, Romance, Sci-Fi, Thriller, War, Western) | one-hot | items | content model, diversity |

**Total:** 16 user, 30 item (19 genre flags), 3 user-item features.

## Materialised snapshots

| Snapshot | Built from | as_of (UTC) | Source interactions | Users (cold-start) | Items | Data fingerprint |
|---|---|---|---:|---:|---:|---|
| `validation` | `train_inner` split | 1998-02-17T18:36:36 | 72002 | 952 (262) | 1688 | `8ad2974f0f6a` |
| `train` | `train` split | 1998-03-07T02:21:09 | 80003 | 952 (201) | 1688 | `6f6c95e62910` |

- `validation` snapshot: used for hyper-parameter selection (models fit on `train_inner`, scored on `val`).
- `train` snapshot: used for final training, test evaluation **and** serving (`src/predict.py`).

## Storage and consistency guarantees

- Storage: `data/features/<snapshot>/{user_features,item_features,user_genre_profile}.parquet` + `metadata.json`.
- Point-in-time correctness: a snapshot only uses interactions with `timestamp <= as_of` (unit-tested in `tests/test_preparation_features.py`).
- Registry check: materialisation fails if a column is produced that is not registered here, or a registered feature is missing.
- Null policy: every feature is populated for users with history; for cold-start users only `user_days_since_last_interaction` is undefined (NaN) and all other features take documented defaults (count 0, global mean rating, `none` genre).

## Usage (same API for training and prediction)

```python
from src.features.feature_store import FeatureStore
fs = FeatureStore("train")
fs.user_features([1, 945])                      # user entity features
fs.item_features([50, 181])                     # item entity features
fs.user_item_features([1, 1], [50, 181])        # on-demand pairwise features
fs.genre_affinity_matrix(user_ids, item_ids)    # vectorised ui_genre_affinity used by the hybrid model
```
